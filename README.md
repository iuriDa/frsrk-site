# Сайт Федерации Роуп Скиппинга Республики Крым — этап 1.4

Обновлённая рабочая версия сайта на Next.js, TypeScript и Tailwind CSS.

## Что изменено

- верхняя голубая полоса — чистая декоративная полоса высотой ровно 20 px, без ссылок и иконок;
- VK и Telegram перенесены в белую полосу шапки (desktop, справа от названия) и в раскрытое мобильное меню (блок «Мы в социальных сетях»);
- Telegram ведёт на официальную группу ФРСРК;
- логотип вынесен отдельным верхним слоем и проходит поверх голубой, белой и красной полос;
- название федерации остаётся в белой части и выровнено по левому краю;
- название стало тоньше, компактнее и минималистичнее;
- красная полоса имеет высоту ровно 20 px;
- навигация получила глубокий тёмно-синий фон;
- текст вкладок белый, размером 9 px;
- все вкладки собраны и отцентрованы по центру навигационной полосы;
- Hero собран из отдельных слоёв: тёмная спортивная арена и спортсмены;
- спортсмены двигаются отдельно от фона и создают эффект глубины;
- добавлена мягкая тень, появление и параллакс от движения мыши;
- в футер добавлено «Все права защищены»;
- в футер добавлена подпись «Разработан и создан Данильченко Ю. Л.»;
- предупреждение hydration mismatch от расширений браузера подавлено на уровне body;
- локальный сервер закреплён за `http://localhost:3002`.

## Запуск на Mac

Откройте Terminal и перейдите в папку проекта:

```bash
cd ~/Documents/web-site-frsrk/frsrk-site-stage1-4
```

Первый запуск или исправление системных зависимостей:

```bash
npm run reset:mac
npm run dev
```

Обычный последующий запуск:

```bash
npm run dev
```

Откройте:

```text
http://localhost:3002
```

Terminal должен оставаться открытым, пока сайт работает.

## Команды

- `npm run dev` — локальная разработка на `http://localhost:3002`.
- `npm run lint` / `npm run typecheck` — статические проверки.
- `npm run build:local` — сборка с временным адресом `http://localhost:3002` (без реального домена) — удобно для локальной проверки, что сборка вообще проходит.
- `npm run check` — полная локальная проверка: `lint` + `typecheck` + `build:local`.
- `npm run build` — production-сборка. Требует переменную окружения `NEXT_PUBLIC_SITE_URL` с реальным доменом Федерации — без неё сборка намеренно завершится ошибкой (см. `src/lib/site-url.ts`), чтобы localhost не попал в публичные metadata, sitemap и robots.

## Production-сборка и запуск

Проект собирается с `output: "standalone"` (Next.js кладёт минимальный сервер в `.next/standalone`, но **не** копирует туда `public/` и `.next/static/` — это ожидаемое поведение Next.js).

Локальный прод-тест на Mac:

```bash
NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru npm run build
npm start
```

`npm start` автоматически (через `prestart`) докопирует `public/` и `.next/static/` в `.next/standalone/`, после чего запустит `node .next/standalone/server.js`.

Для реального деплоя используйте `Dockerfile` в корне проекта — он уже сам корректно копирует `public` и `.next/static` в финальный слой образа на этапе multi-stage build.
