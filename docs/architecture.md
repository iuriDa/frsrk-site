# Архитектура этапа 1

## Стек

- Next.js App Router
- React Server Components по умолчанию
- TypeScript strict
- Tailwind CSS 4
- Lucide React

## Принципы

1. Контент отделён от компонентов.
2. Официальные сведения не зашиваются в JSX.
3. Неподтверждённая информация хранится отдельно.
4. Календарь использует единую модель события для соревнований, обучения, сборов и фестивалей.
5. Представители вынесены в самостоятельный раздел.
6. Разделы «Спортивные направления» и «Проекты» отсутствуют.
7. Раздел «Для СМИ» существует как черновик и не включён в главное меню.
