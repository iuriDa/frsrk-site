# Административная панель — этап 2

## Новости

Администратор должен иметь возможность:

- создать новость;
- загрузить обложку и галерею;
- сохранить черновик;
- опубликовать;
- отметить «Показывать на главной»;
- выбрать одну главную новость;
- выбрать до трёх важных новостей;
- изменить порядок показа;
- привязать мероприятие и документы.

Поля модели уже подготовлены в `src/content/news.ts`.

## Антидопинг

Администратор должен управлять:

- актуальными документами;
- архивными документами;
- внешними ссылками;
- датой последней проверки ссылки;
- ответственным лицом;
- документом о назначении.

## Муниципалитеты

Администратор должен управлять:

- территорией;
- представителем;
- клубами;
- тренерами;
- спортсменами сборной;
- мероприятиями;
- новостями и результатами.
